Detailed Description

AVL Balanced binary search tree uses balance factors on each node to keep the tree balanced on each insertion or deletion.

◆ avl_tree_height()

unsigned avl_tree_height ( bsearch_tree_ref_t *  tree)

Compute the height of an AVL tree.

The usual way to compute the height of a binary tree is a logarithmic operation. However to equilibrate an AVL tree we keep the height of each node across insertion and deletion. Therefore this function provide a very efficient way (a simple read) to retrieve the height of the root of an AVL tree.

Complexity_: \(O(1)\)

Parameters
treePointer to the tree
Returns
The height of the tree (0 if the tree is empty ie. has no root)
