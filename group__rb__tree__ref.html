Detailed Description

Red-Black Balanced binary search tree uses color tags on each node to keep the tree balanced on each insertion or deletion.

Inserts an element into the tree.

Insert an element into the tree. The tree will take ownership of the element and free it (if bsearch_tree_ref::free_element != NULL) when the tree is freed.

Complexity: \(O(ln(n))\)

Parameters
treePointer to the tree
valuePointer to the element to compare
foundIf the element was already in the tree and found != NULL then after the call *found points to the node that contains the element equal to value
Returns
ERROR_KEY_ALREADY_EXISTS if value was found in the tree and ERROR_NO_ERROR otherwise
