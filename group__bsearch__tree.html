Inserts an element into the tree.

Insert an element into the tree. The tree will take ownership of the element and free it (if bsearch_tree::free_element != NULL) when the tree is freed.

Complexity: \(O(ln(n))\) if the tree is balanced, \(O(n)\) otherwise

Parameters
treePointer to the tree
valuePointer to the element to insert
foundIf the element was already in the tree and found != NULL then after the call *found points to the node that contains the element equal to value
Returns
ERROR_KEY_ALREADY_EXISTS if value was found in the tree and ERROR_NO_ERROR otherwise
