◆ compare_fn_t

compare_fn_t

Typedef for pointer to a comparison function.

A comparison function takes to pointers as arguments, it should return -1 if the first element is smaller than the second, 1 if the first element is greater and 0 if they are equals. Any other value returned may lead to Undefined Behavior.
