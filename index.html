Data Structures and Algorithms in C

This library contains a well-tested and documented but non-exhaustive set of common Data Structures and Algorithms.

Installation

This project is build with the meson build system.

  1. Clone this repository
  2. cd into the repository
  3. Setup the project
    meson setup build
  4. (Optional): Configure the project
    meson configure build -Dweight_type=int -Dfail_test=abort
  5. Build the project
    meson compile -C build
  6. (Optional): Test the project
    meson test -C build
    Alternatively if you have it installed you can launch the tests with valgrind:
    meson test --wrap='valgrind --leak-check=full --error-exitcode=1' --timeout-multiplier 2 -C build

The code coverage can be generated by giving Meson the command line flag -Db_coverage=true. This will create three additional target coverage-xml, coverage-text, coverage-sonarqube and coverage-html.

You can generate the coverage-html target with Gcovr using the following command:

ninja coverage-html -C build
  1. Install the project
    meson install -C build

Documentation

You can generate the documentation with:

meson compile doc -C build

Or you can access it online.

Features

Data structures:

  • Doubly-linked lists
  • Binary trees
  • Graphs with adjacency matrix
  • Graphs with adjacency lists

Algorithms

  • Graph traversal: DFS (pre, in and post-order), BFS
  • Single Source Shortest Path: Dijkstra, Bellman, Ford, Ford-Dantzig
