Detailed Description

A dynamic array.

A dynamic array olds a pointer to its data, the size (in bytes) of an element of the array, the current capacity of the buffer, the actual number of elements in the array

The prefered way to iterate over an array_list is using get_array_list_ref():

int* value;
int i;
for(int i = 0; i < array.size; i++) {
value = get_array_list_ref(array, i, int);
printf("%d\n", *value);
// ...
}
